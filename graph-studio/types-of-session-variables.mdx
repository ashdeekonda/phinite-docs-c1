---
title: Types of session variables
description: Capture, tool-returned, user, system, and predefined-tool session variables.
---

Session variables carry state through an Agent Graph run. They are distinct from graph-level definitions in the [Variables panel](/graph-studio/interface/variables-panel).

## Variable categories

| Type | How it is set |
| --- | --- |
| **Capture variables** | Agent extracts values during the run based on capture definitions |
| **Tool-returned capture** | Tools return values in `capture_variables` (custom tools) or full output objects (predefined tools) |
| **User variables** | Passed in the API payload before running conversational or autonomous flows |
| **System variables** | Automatically set each session — e.g. `workflow_id`, `caller_number` (voice), `conversation_history` |
| **Predefined tool output** | Entire tool output object stored as a session variable |

## Capture variables

Capture variables are populated when the agent identifies information matching your **Capture** definitions in the node drawer ([Capture variables](/graph-studio/capture-variables-in-agent-node)).

## Tool-returned variables

Custom tools return captures in a `capture_variables` dictionary — each key becomes a session variable.

## System variables

| Variable | When available |
| --- | --- |
| `workflow_id` | Every run — unique execution id |
| `caller_number` | Voice calls — caller phone number |
| `conversation_history` | Throughout the workflow execution |
