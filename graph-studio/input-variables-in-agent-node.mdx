**Input variables** control which session variables are visible to a specific agent node. Scope inputs to only what the step needs.

## Supported sources

| Source | Description |
| --- | --- |
| **Tool capture variables** | Values returned by tools during execution — use the exact variable name |
| **Other agent capture variables** | Captures from other agent nodes in the same graph |
| **Self capture variables** | Values the same node captured in earlier turns |
| **User variables (API)** | Keys from the `user_variable` payload when invoking via Agent Graph API |

<AccordionGroup>
  <Accordion title="Tool capture variables">
    Enter the exact variable name returned by a tool's `capture_variables` or predefined tool output.
  </Accordion>
  <Accordion title="Other agent capture variables">
    Reference captures from upstream Master or Child Agent nodes in the graph.
  </Accordion>
  <Accordion title="Self capture variables">
    Use values this node captured earlier in the same session when multi-turn behavior applies.
  </Accordion>
  <Accordion title="User variables (Agent Graph API)">
    Map keys from the API request `user_variable` object into this node's inputs.
  </Accordion>
</AccordionGroup>

## Configure input variables

1. Select an agent node → drawer **Variables** tab.
2. Under **Input Variables**, add each required session variable by name.
3. **Save** the graph.

<Tip>
  Only add variables the agent needs — smaller input scope improves performance and focus.
</Tip>
