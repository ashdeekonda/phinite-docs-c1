An **Agent Graph** is the unit you create and open from Workspace Home.

## Types

| Type | Role | Typical deploy targets |
| --- | --- | --- |
| **Conversational** | Voice & chat with users | Channel, Chat API, A2A |
| **Autonomous** | Background tasks without a live user | API trigger, Cron, A2A (coming soon) |

Create via **New Agent Graph** → choose type. You can change type later.

![Create Agent Graph](/images/v2/agents/01-new-agent-graph-modal.png)

## Note

Workspace filters may still show an **Email** chip. New graphs only offer Conversational and Autonomous.
