title: Builds
description: Freeze an agent graph and tool versions into a deployable build.
---

A **Build** is an immutable snapshot of your agent graph and pinned tool versions.

## Steps

1. In Graph Studio, **Save** the graph.
2. Click **Build**.
3. Wait while Phinite validates the graph and packages tool versions.
4. Add a **Description**.
5. Confirm **AGENT GRAPH** version and **TOOLS** (click **Publish** on any unpublished tool).
6. Click **Create Build**.

Builds appear under Studio → **Agent Builds**.
