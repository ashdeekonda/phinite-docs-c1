<Note>
  Use single-endpoint **API** mode only for **Autonomous Agent Graphs** that complete in under ~120–150 seconds. For longer work, use [Background task](/triggers-intents/triggers/bg_task) mode.
</Note>

### Overview

The single endpoint API mode provides **synchronous execution** of **Autonomous Agent Graphs**. The API call waits for the graph run to complete and returns the final result in the response.

**Limitations:**

- Maximum execution time: **120–150 seconds**
- Not recommended for complex or multi-step graphs
- Best suited for simple, fast operations

### Endpoint

```text
POST https://app.phinite.ai/api/v1/ai/trigger/{workspace_id}/{trigger_id}/{environment}
```

### Request payload

```json
{
  "message": "",
  "user_variables": {"key1":"value1", "key2":"value2"}
}
```

#### Field descriptions

| Field | Type | Description |
| :-- | :-- | :-- |
| `message` | String | The first message sent when the session starts. Can be empty if not required. |
| `user_variables` | Object | Session variables to initialize the run. Available throughout the Agent Graph. |

### Response format

The API directly returns completed or failed status:

**Success Response (200 OK):**

```json
{
  "workflow_id": "workflowid-uuid",
  "response": {
    "key1": "value1",
    "key2": "value2"
  },
  "status": "completed",
  "logs": [...],
  "requires_input": false,
  "error": null
}
```

**Failed Response (200 OK):**

```json
{
  "workflow_id": "workflowid-uuid",
  "response": {},
  "status": "failed",
  "logs": [...],
  "requires_input": false,
  "error": "Error details here"
}
```
