<Note>
  **Cron** triggers run **Autonomous Agent Graphs** on a schedule — no external HTTP caller after configuration. Assign an **Agent Build** per **DEV / UAT / PROD** in **Integrations** → **Triggers** or **Deploy** → **Cron job**.
</Note>

### Overview

Cron job mode schedules **Autonomous Agent Graphs** to execute at specified intervals on Phinite. This removes the need for external schedulers.

**Configuration:**

1. Set the schedule in the platform trigger UI.
2. Agent Graphs execute in the background at the specified time.
3. No API calls required once configured.
4. Ideal for recurring tasks — daily reports, data syncs, health checks, notifications.

**Use cases:**

- Daily / weekly / monthly reports
- Periodic data synchronization
- Scheduled cleanup tasks
- Regular health checks
- Automated reminders

### Set up a Cron trigger

1. **Save** the Autonomous Agent Graph and create an **Agent Build**.
2. Open **Integrations** → **Triggers** → create **Cron** trigger (or Studio **Deploy** → **Cron job**).
3. Enter the cron expression and any default **message** / **user_variables**.
4. Assign the build to **DEV**; confirm the first run in [Observability logs](/observability/logs).
5. Promote to **UAT** / **PROD** when validated.

<Tip>
  Design Cron graphs to be **idempotent** — duplicate ticks should not double-apply side effects.
</Tip>
